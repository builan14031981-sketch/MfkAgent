# MfkAgent 产品企划书 V3.0

**版本：V3.0**
**状态：产品方向重构版**
**用途：MfkAgent 长期产品设计基准文档**

---

# 一、产品定位

## 产品名称

MfkAgent

---

# 1.1 产品定义

MfkAgent 是一款：

> 面向个人开发者、专业用户的 AI 工作助手。

它通过：

* AI 对话
* 项目上下文管理
* 文件理解
* 模型调用
* 个人记忆

帮助用户完成真实工作任务。

---

# 1.2 核心理念

MfkAgent 不追求：

> 拥有最多 AI 功能。

而追求：

> 成为一个长期可靠的个人 AI 工作伙伴。

核心体验：

```
用户目标

↓

工作环境

↓

AI理解上下文

↓

提供分析 / 建议 / 辅助

↓

沉淀工作过程
```

---

# 二、产品方向

## MfkAgent 是什么

MfkAgent 是：

```
AI 工作空间
```

而不是：

```
聊天机器人
```

区别：

普通聊天：

```
用户

↓

问题

↓

回答
```

MfkAgent：

```
用户

↓

项目

↓

任务

↓

上下文

↓

AI协作

↓

结果沉淀
```

---

# 三、产品边界

## 3.1 不做的方向

以下方向不属于 MfkAgent 核心定位。

---

## ❌ ChatGPT网页复刻

原因：

MfkAgent 不只是聊天窗口。

---

## ❌ AI玩具集合

禁止：

* 大量无意义 AI 功能堆叠
* 娱乐化功能优先
* 功能展示大于实际价值

---

## ❌ Agent制作平台

V1阶段禁止：

* 用户创建 Agent
* Agent 编辑器
* Agent 市场
* Agent 分享
* Agent 发布

原因：

MfkAgent 的目标不是：

> 让用户制造机器人。

而是：

> 提供经过设计的 AI 工作伙伴。

---

## ❌ 复杂自动化平台

暂不做：

* Workflow Builder
* 节点编辑器
* 自动任务编排

---

## ❌ 插件生态

暂不做：

* Plugin Marketplace
* MCP管理中心

---

# 五、Workspace设计

## 定义

Workspace 是用户的 AI 工作空间。

负责：

* 管理项目
* 管理聊天
* 管理上下文

---

# 5.1 Project

Project 是核心工作单位。

例如：

```
MfkAgent项目

Minecraft项目

简历优化

个人网站
```

---

Project包含：

```
Project

id

name

path

createdAt

updatedAt
```

---

注意：

Project ID 与路径必须分离。

原因：

避免文件路径变化导致数据失效。

# 七、Agent设计原则

## 7.1 Agent定义

MfkAgent中的 Agent：

不是机器人。

而是：

> 一个具有固定工作方式、行为规则和能力范围的 AI 工作角色。

---

结构：

```
Agent

↓

Identity

↓

Behavior

↓

Personality

↓

Capability

↓

Model
```

---

# 7.2 Agent产品原则

V1：

只提供系统预设 Agent。

用户：

可以：

✅ 选择

✅ 使用

✅ 调整部分行为参数

不能：

❌ 创建

❌ 修改核心Prompt

❌ 发布

❌ 分享

---

# 7.3 预设Agent方向

例如：

## 小暖

定位：

温暖陪伴型 AI。

特点：

* 理解用户状态
* 提供支持
* 降低压力

---

## 理性分析师

定位：

决策审查型 AI。

特点：

* 检查逻辑
* 发现风险
* 挑战假设

---

## 代码助手

定位：

软件开发辅助。

特点：

* 分析代码
* 提供架构建议
* 关注维护成本

---

# 八、人格系统设计

## 8.1 设计目标

用户可以调整：

> AI回应方式。

不是修改：

> AI身份。

---

# 8.2 理性感性系统

五档：

```
极度感性

↓

偏感性

↓

平衡

↓

偏理性

↓

极度理性
```

对应：

```
0%

25%

50%

75%

100%
```

---

# 8.3 Prompt组合原则

禁止：

简单修改 temperature。

采用：

动态 Prompt 组合。

结构：

```
系统规则

+

Agent身份

+

人格参数

+

用户偏好

+

任务上下文

↓

最终System Prompt
```

---

# 九、Memory设计原则

## 9.1 Memory定位

Memory：

用于保存长期有效信息。

例如：

用户偏好：

```
喜欢简洁回答
```

项目记忆：

```
MfkAgent使用Electron
```

---

## 9.2 Memory不做

禁止：

* 复杂知识库替代品
* 自动收集所有聊天
* 无限制保存信息

---

* 炫技动画

```
Page

↓

Container

↓

Component

↓

Element
```

---

# 12.2 定位规范

禁止：

全局：

```

fixed
```

正确：

```
页面容器

↓

功能区域

↓

组件容器

↓

```

---

# 12.3 样式规范

必须：
