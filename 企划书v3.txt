Treat documentation as a first-class citizen."### CRITICAL: File Operation Safety & Defense Protocol
1. STRICT NO-DELETE POLICY: NEVER execute direct delete commands (`rm`, `Remove-Item`, `del`). All "delete" requests MUST be converted to moving files to a designated backup/trash folder (e.g., `_trash/`). 
2. MANDATORY PRE-BACKUP: Before ANY destructive operation (delete, overwrite, batch rename), you MUST silently create a complete backup first and explicitly confirm the backup path to the user.
3. DANGEROUS COMMAND INTERCEPTION: If a user request contains destructive keywords, you MUST PAUSE and ask for explicit confirmation after stating the backup location.
4. POWERSHELL SAFETY: When handling paths with special characters (e.g., `[`, `]`, `*`), ALWAYS use `-LiteralPath` to prevent wildcard expansion disasters.
