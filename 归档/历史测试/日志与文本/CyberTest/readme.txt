CyberTest 项目说明
==================

这是一个简单的 Python 脚本示例，用于打印酷炫的赛博朋克风格台词。

文件说明
--------
- hello.py   : 主脚本，包含赛博朋克台词的打印逻辑
- readme.txt : 本说明文件

如何运行
--------

1. 环境要求：
   - Python 3.x（任意版本均可，脚本只用了标准库）
   - 无需额外安装任何第三方依赖

2. 运行方法（任选其一）：

   方法一：直接运行
   ```
   python hello.py
   ```

   方法二：指定模块运行
   ```
   python -m hello
   ```

   方法三：进入 CyberTest 目录后运行
   ```
   cd CyberTest
   python hello.py
   ```

3. 预期输出：
   脚本会逐行打印出几条赛博朋克风格的台词，
   每行之间有约 0.6 秒的间隔，模拟终端启动的节奏感。

提示
----
- 如果提示 'python' 不是内部或外部命令，请尝试使用 'python3' 命令。
- 脚本使用了 time.sleep() 做节奏控制，属标准库，无需安装。
