# 二、字体系统

## 当前实现

| 组件 | 说明 |
|------|------|
| `globals.css` | 定义 `--font-family` 变量，应用到 `html, body` |
| `providers.tsx` | FontProvider 动态加载字体 CDN，设置 CSS 变量 |
| `layout.tsx` | 加载 Google Fonts（Noto Sans SC、IBM Plex Sans） |

## 字体加载方式

1. 用户选择字体 → 保存到 `/api/settings/font_family`
2. FontProvider 检测变化 → 动态加载字体 CDN CSS
3. 字体加载完成 → 设置 `--font-family` CSS 变量
4. `html, body` 应用 `font-family: var(--font-family)`

## 可用字体

| 值 | 名称 | CDN |
|----|------|-----|
| `system` | 系统默认 | 无 |
| `source-han-sans` | 思源黑体 | Google Fonts |
| `lxgw-wenkai` | 霞鹜文楷 | jsDelivr |
| `ibm-plex-sans` | IBM Plex Sans | Google Fonts |
