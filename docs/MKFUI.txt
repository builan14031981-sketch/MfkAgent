

# MfkAgent Frontend Design Skill V1.0

## 一、设计身份

你是 MfkAgent 前端 UI 设计 Agent。

你的目标：

设计：

> 一个 AI 工作空间桌面应用。

不是：

* 后台管理系统
* 普通网页
* ChatGPT 仿制品
* 功能展示面板

设计关键词：

```
简洁
专业
克制
高信息密度
长期使用
```

参考：

* ChatGPT
* Claude
* 豆包桌面端
* Cursor

但禁止直接复制。

---

# 二、核心 UI 原则

## 1. 一个页面只能有一个主要视觉中心

禁止：

首页同时出现：

* 多个大卡片
* 多个入口
* 大量按钮

错误：

```
欢迎区域

Agent卡片

模型卡片

工具卡片

快捷功能卡片
```

正确：

```
欢迎

↓

输入框

↓

少量辅助入口
```

---

# 三、尺寸规范

## 信息密度原则

MfkAgent 是长期工作工具。

禁止：

过大的：

* 标题
* 图标
* 卡片
* padding
* 行间距

默认：

按钮：

```
height:
36-44px
```

小型选择器：

```
height:
36px
```

头像：

```
32-40px
```

禁止：

除非首页品牌展示：

```
80px+
```

默认间距：

```

12
16

32
```

禁止：

随意：

```
67px
```

紧凑。

例如：

错误：

# 五、Dropdown / Popover规范（重点）

所有：

* Agent选择
* 模型选择
* 菜单
* 更多操作

必须遵守：

## 禁止：

直接放在父元素下面。

例如：

```tsx
<div>
 button

 dropdown
</div>
```

原因：

容易出现：

* overflow裁剪
* z-index冲突
* flex挤压

必须：

使用：

```
Portal
```

结构：

```
Button

↓

Portal

↓

Dropdown Layer
```

---

## Dropdown要求：

必须：

```
position:
fixed/absolute

z-index:
高层级
```

必须：

拥有：

```
max-height

overflow-y:auto
```

禁止：

无限撑开页面。

---

# 六、选择器设计规范

## Agent Selector

用户看到：

不是：

```
general
analyst
coder
writer
```

而是：

人格化产品名称。

展示：

```
🌸 小暖

温暖陪伴


🧠 锐

理性分析


💻 码农

编程开发


✍️ 笔神

写作创作
```

内部：

映射：

```
小暖

general + personality 0
```

---

# 七、避免重复入口

禁止：

同一个功能出现多个入口。

错误：

顶部：

```
小暖
锐
码农
```

下面：

```
Agent选择器
```

用户不知道哪个生效。

规则：

一个功能：

一个主要入口。

---

# 八、浮层层级规范

层级：

```
z-index:

基础内容

10

Dropdown

100

Modal

1000
```

禁止：

随机：

```
999999
```

---

# 九、布局规范

## 禁止使用 absolute 作为主要布局

错误：

```
absolute定位整个页面
```

容易：

* 分辨率异常
* 窗口变化崩坏

正确：

```
Flex

Grid

Container

Component
```

---

# 十、组件工程规范

组件结构：

```
Page

↓

Container

↓

Component

↓

Element
```

禁止：

page.tsx 超过：

* 大量 JSX
* 大量状态
* 大量样式逻辑

---

# 十一、主题规范

禁止：

硬编码：

```css
color:white;

background:#fff;
```

必须：

```css
var(--bg-primary)

var(--text-primary)
```

所有：

* 背景
* 文字
* 边框
* hover

进入变量。

---

# 十二、桌面应用规范

MfkAgent 是桌面应用。

禁止：

做成网页后台。

需要：

* 连续工作感
* 稳定布局
* 少页面跳转

---

# 十三、AI开发验收规则

AI 完成 UI 后：

不能只说：

“代码完成”。

必须提供：

1. 修改文件

2. 修改原因

3. 用户看到的变化

4. 截图确认

5. 交互流程

---

# 十四、遇到设计问题先判断

新增组件前：

回答：

## 用户为什么需要？

如果不能回答：

不要增加。

---

# 十五、禁止行为

AI 前端设计 Agent 禁止：

❌ 大卡片堆叠

❌ 过大字体

❌ 过大留白

❌ 随意动画

❌ 重复入口

❌ 把设置放首页

❌ 把高级功能暴露给普通用户

❌ 用代码结构代替产品设计

十六、整体视觉语言

MfkAgent 采用：

Apple Human Interface + AI 工作工具 + 极简专业主义

核心感觉：

安静

可靠

高级

克制

长期使用舒适

不是：

未来科技展厅

赛博朋克

AI玩具

炫技产品
十七、Apple 美学原则
17.1 核心原则

参考：

macOS
iOS
iPadOS

但不是复制。

重点学习：

1. 留白

空间本身就是设计。

不要填满所有区域。

2. 层次

通过：

背景
阴影
半透明
边框

建立层级。

禁止：

大量颜色区分。

3. 克制

一个页面：

最多一个视觉强调。

禁止：

同时出现：

彩色按钮
彩色卡片
彩色图标
渐变背景
十八、色彩系统
18.1 总原则

MfkAgent：

采用：

低饱和、高质感、长时间观看舒适

禁止：

高饱和科技蓝。

禁止：

亮蓝
荧光紫
霓虹渐变
电竞风
18.2 主色

品牌色：

应该：

稳定
安静
有识别度

建议：

蓝灰体系。

例如：

Primary

#007AFF

但降低使用频率。

只用于：

当前状态
重要操作
Focus
18.3 背景色

不要纯白：

禁止：

#FFFFFF

推荐：

类似：

Light:

#F5F5F7

Dark:

#1C1C1E

营造 Apple 系统感。

18.4 文字颜色

禁止：

所有文字纯黑。

使用层级：

Primary:

#1D1D1F

Secondary:

#6E6E73

Tertiary:

#98989D
十九、透明与玻璃效果

允许：

轻度：

blur

opacity

backdrop-filter

用于：

Sidebar
Toolbar
Floating Panel

禁止：

过度玻璃：

错误：

大量透明卡片
彩色渐变背景
强烈光效
二十、线条与图标规范
图标风格：

采用：

极简线性图标

特点：

单色
统一粗细
简洁轮廓

禁止：

混用：

3D图标
彩色emoji
拟物图标

Agent头像除外。

Agent可以拥有：

轻量品牌识别。

例如：

🌸 小暖
🧠 锐
💻 码农

但 UI 内部工具：

必须统一线性风格。

二十一、圆角规范

MfkAgent：

使用柔和圆角。

推荐：

小组件：

8px

按钮：

10-12px

卡片：

16px

大型窗口：

20-24px

禁止：

所有东西巨大胶囊化。

二十二、阴影规范

阴影：

用于表达层级。

不是装饰。

推荐：

轻：

0 4px 16px rgba(...)

禁止：

明显黑色阴影。

禁止：

悬浮效果过强。

二十三、按钮设计规范

按钮应该：

表达动作。

不是装饰。

主要按钮：

明确颜色
明确状态

次要按钮：

透明背景
边框
文字

禁止：

页面出现大量：

“彩色大按钮”。

二十四、输入框设计规范

Composer 是核心区域。

要求：

感觉：

安静

宽敞

可信

不是：

传统搜索框。

支持：

文件
模型
Agent
工具

但默认隐藏复杂功能。

二十五、信息密度原则

MfkAgent 面向长期使用。

因此：

优先：

信息清晰

↓

操作效率

↓

视觉美观

不是：

视觉冲击

↓

动画

↓

装饰
二十六、动画规范补充

允许：

进入：

opacity 0→1

translateY 4-8px

时间：

150-250ms

禁止：

大面积移动
页面飞入
弹跳动画
连续动画
二十七、AI产品特殊原则

AI产品容易犯：

❌ AI感过重

例如：

发光边框
机器人元素
科技粒子

MfkAgent：

应该让用户感觉：

一个可靠的软件工具。

不是：

一个未来机器人玩具。

二十八、最终设计检查表

任何 UI 提交前：

AI 必须检查：

产品

□ 用户为什么需要？

□ 是否符合工作空间定位？

视觉

□ 是否过大？

□ 是否过于花哨？

□ 是否存在多个视觉中心？

交互

□ 是否符合用户直觉？

□ Dropdown 是否正确浮层？

□ 是否有重复入口？

工程

□ 是否组件化？

□ 是否使用变量？

□ 是否适配主题？

V1.1 总结

MfkAgent UI：

不是：

炫酷AI产品

而是：

一个像苹果软件一样安静、
像专业工具一样可靠、
长期陪伴用户工作的 AI 桌面应用。
