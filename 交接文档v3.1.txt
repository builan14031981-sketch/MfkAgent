# 三、后端新增功能详情

## 1. 置顶功能持久化 ✅

**数据模型：**
```python
class Chat(Base):
    # 现有字段...
    is_pinned = Column(Boolean, default=False)
```

**API：**
```python
PATCH /api/chat/{id}
{
  "is_pinned": true
}
```

---

## 2. 聊天列表排序 ✅

**排序规则：**
1. 置顶的聊天排在最前面
2. 同级按更新时间降序

---

## 3. 人格系统集成 ✅

**API 参数：**
```python
POST /api/chat/{id}/send
{
  "content": "消息内容",
  "personality_level": 50  # 0-100
}
```

**人格级别：**
| 级别 | 说明 |
|------|------|
| 0 | 极度感性 |
| 25 | 偏感性 |
| 50 | 平衡 |
| 75 | 偏理性 |
| 100 | 极度理性 |

---

## 4. 工具调用返回格式 ✅

**API：**
```python
POST /api/tools/call
{
  "tool": "web_search",
  "params": {"query": "搜索内容"}
}
```

**返回格式：**
```json
{
  "success": true,
  "result": { ... }
}
```

# 六、API 端点清单

## 核心 API

| 端点 | 说明 | 状态 |
|------|------|------|
| `GET /api/agents` | 获取Agent列表 | ✅ |
| `GET /api/models/models` | 获取模型列表 | ✅ |
| `POST /api/chat` | 创建Chat | ✅ |
| `GET /api/chat` | 获取Chat列表（置顶排序） | ✅ |
| `PATCH /api/chat/{id}` | 更新Chat（支持is_pinned） | ✅ |
| `DELETE /api/chat/{id}` | 删除Chat | ✅ |
| `POST /api/chat/{id}/send/stream` | 流式发送 | ✅ |
| `POST /api/chat/{id}/send` | 发送（支持personality_level） | ✅ |
| `GET /api/chat/{id}/messages` | 获取消息 | ✅ |
| `GET /api/settings` | 获取设置 | ✅ |
| `PUT /api/settings/{key}` | 更新设置 | ✅ |

## 工具 API

| 端点 | 说明 | 状态 |
|------|------|------|
| `GET /api/tools` | 列出所有工具 | ✅ |
| `POST /api/tools/call` | 调用工具 | ✅ |
| `GET /api/tools/definitions` | 获取工具定义 | ✅ |
