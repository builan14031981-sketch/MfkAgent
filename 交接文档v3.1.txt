# 三、新增功能详情

## 1. 右键菜单（聊天列表）

**功能：**
- 重命名：内联编辑，Enter确认，Esc取消
- 置顶/取消置顶：显示📌图标，置顶聊天排在前面
- 删除：删除聊天

**交互：**
- 右键点击聊天项 → 显示菜单
- 点击外部 → 关闭菜单

---

## 2. 按钮动效

**已添加动效的元素：**

| 元素 | hover | active |
|------|-------|--------|
| 新建任务 | 背景变亮 | scale(0.98) |
| 聊天项 | 背景变亮 | - |
| Memory/Settings | 背景变亮，文字变亮 | - |
| 删除按钮 | 显示，背景变亮 | - |
| Agent选择 | 边框变主题色 | - |
| 发送按钮 | 背景变亮，scale(1.05) | scale(0.95) |

---

## 3. 深色模式优化

**字体颜色：**
```css
--text-level-1: #ffffff;  /* 页面标题 - 纯白 */
--text-level-2: #f5f5f7;  /* 正文内容 */
--text-level-3: #b0b0b5;  /* 辅助信息 */
```

**背景层级：**
```css

--bg-level-3: #2c2c2e;  /* 卡片/输入框 */
```

# 四、需要后端支持的功能

## 1. 置顶功能持久化 ⏳

**当前状态：** 前端使用内存状态，刷新后重置

**需要后端：**
- 在 Chat 模型中添加 `is_pinned` 字段
- API: `PATCH /api/chat/{id}` 支持 `is_pinned` 参数
- 列表接口返回时按 `is_pinned` 排序

**数据模型修改：**
```python
class Chat(Base):
    # 现有字段...
    is_pinned = Column(Boolean, default=False)  # 新增
```

---

## 2. 聊天列表排序 ⏳

**当前状态：** 按 `updated_at` 排序

**需要后端：**
- 支持按置顶状态 + 更新时间排序
- 置顶的聊天始终在最前面

---

## 3. 人格系统集成 ⏳

**当前状态：** 前端有滑块UI，后端有Prompt组合

**需要后端：**
- 确认 `personality_level` 参数在 `/send` 和 `/send/stream` 接口中生效
- 返回的人格Prompt应该根据level动态生成

---

## 4. 工具调用UI集成 ⏳

**当前状态：** 后端已完成5个工具API

**需要后端：**
- 确认工具调用的返回格式
- 提供工具执行结果的结构化数据

# 六、API 端点清单

## 核心 API

| 端点 | 说明 | 状态 |
|------|------|------|
| `GET /api/agents` | 获取Agent列表 | ✅ |
| `GET /api/models/models` | 获取模型列表 | ✅ |
| `POST /api/chat` | 创建Chat | ✅ |
| `GET /api/chat` | 获取Chat列表 | ✅ |
| `PATCH /api/chat/{id}` | 更新Chat | ✅ |
| `DELETE /api/chat/{id}` | 删除Chat | ✅ |
| `POST /api/chat/{id}/send/stream` | 流式发送 | ✅ |
| `GET /api/chat/{id}/messages` | 获取消息 | ✅ |
| `GET /api/settings` | 获取设置 | ✅ |
| `PUT /api/settings/{key}` | 更新设置 | ✅ |

## 需要增强的 API

| 端点 | 需要增强 | 优先级 |
|------|----------|--------|
| `PATCH /api/chat/{id}` | 支持 `is_pinned` 字段 | ★★★★ |
| `GET /api/chat` | 按置顶状态排序 | ★★★★ |
| `POST /api/chat/{id}/send` | 确认 personality_level 生效 | ★★★ |
