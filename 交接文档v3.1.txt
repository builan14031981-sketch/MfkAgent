## 当前页面架构

```
layout.tsx
└── AppLayout (客户端组件)
    ├── Sidebar (固定存在)
    │   ├── 新建任务按钮
    │   ├── 项目列表
    │   ├── 聊天列表 (按时间分组：今天、昨天)
    │   └── Memory / Settings 按钮
    ├── SettingsPanel (全局弹窗)
    ├── MemoryPanel (全局弹窗)
    └── MainContent (路由切换)
        ├── / → Home (欢迎界面 + 输入框)
        ├── /chat/[id] → ChatPage (聊天界面)
        └── /projects/[id]/* → ProjectPages (文件浏览/内容/搜索)
```

---

## 当前Chat流程

```
用户输入
    ↓
首页 handleSend
    ↓
createChat() → POST /api/chat
    ↓
跳转 /chat/[id]?message=xxx
    ↓
Chat页面读取URL参数
    ↓
sendMessageStream() → POST /api/chat/[id]/send/stream
    ↓
后端保存 user message + 调用模型 + 保存 assistant message
    ↓
前端显示流式回复
    ↓
清除URL参数
```

# 六、开发注意事项

- 在页面中创建自己的Sidebar
- 在页面中创建自己的Settings/Memory面板

---

## 2. 使用已有hook

- useChat: Chat CRUD

---

## 3. 国际化规范

所有用户可见文字必须使用 t() 函数：

```tsx
// ❌ 错误
<span>加载中...</span>

// ✅ 正确
<span>{t("common.loading")}</span>
```
