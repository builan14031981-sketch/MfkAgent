# 三、V1 核心工作流

```
选择 Agent → 选择模型 → 开始对话 → 流式回复 → 历史保存
```

## 完整流程

```
用户打开 MfkAgent
    ↓
首页：选择 Agent + 选择模型
    ↓
输入问题
    ↓
创建 Chat → 跳转聊天页面
    ↓
自动发送消息 → 流式显示 AI 回复
    ↓
消息保存 → Sidebar 显示聊天历史
    ↓
点击历史聊天 → 恢复上下文
```

# 五、API 端点清单

## 核心 API

| 端点 | 说明 |
|------|------|
| `GET /api/agents` | 获取Agent列表 |
| `GET /api/models/models` | 获取模型列表 |
| `POST /api/chat` | 创建Chat |
| `GET /api/chat` | 获取Chat列表 |
| `POST /api/chat/{id}/send/stream` | 流式发送消息 |
| `GET /api/chat/{id}/messages` | 获取消息列表 |
| `GET /api/projects` | 获取项目列表 |
| `GET /api/projects/{id}/files` | 获取项目文件 |
| `GET /api/settings` | 获取设置 |
| `PUT /api/settings/{key}` | 更新设置 |
| `GET /api/memory/{agent_id}` | 获取记忆 |
| `POST /api/memory` | 创建记忆 |

## 工具 API (Phase 7)

| 端点 | 说明 |
|------|------|
| `GET /api/tools` | 列出所有工具 |
| `POST /api/tools/call` | 调用工具 |
| `GET /api/tools/definitions` | 获取工具定义 |

# 九、开发注意事项

## 1. 保持架构稳定

当前AppLayout架构已经统一，不要：
- 在页面中创建自己的Sidebar
- 在页面中创建自己的Settings/Memory面板

---

## 2. 使用统一API

所有API调用使用 `lib/api.ts` 中的函数：
- `apiGet<T>(path)` - GET请求
- `apiPost<T>(path, data)` - POST请求
- `apiPatch<T>(path, data)` - PATCH请求
- `apiDelete(path)` - DELETE请求

---

## 3. 国际化规范

所有用户可见文字必须使用 t() 函数：

```tsx
// ❌ 错误
<span>加载中...</span>

// ✅ 正确
<span>{t("common.loading")}</span>
```

数组类型使用 tArray() 函数：

```tsx
const messages = tArray("home.welcome");
```
