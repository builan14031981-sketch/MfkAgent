【滑块第三轮 QA 修复 · 前两轮均未达标，必须按死公式实现】
你在 E:\智慧项目\portfolio-mfkagent\index.html 的滑块又用了 translate3d(position%, -50%, 0)。注意：transform translateX 的百分比是相对元素自身宽度（你的 thumb 只有 30px），所以五档实际位移只有 0/7.5/15/22.5/30px，thumb 几乎钉在轨道左端不动。这是同一个 P0 缺陷第二次出现。

【正确实现（照此实现，不要发挥）】
updateUI 中：
```
updateUI() {
    const pct = this.currentIndex / 4;                       // 0..1
    const px = this.trackRect.width * pct;                   // 轨道宽度的绝对像素
    const halfThumb = 30 / 2;                                // thumb 30px 的一半
    this.thumb.style.transform = `translate3d(${px - halfThumb}px, -50%, 0)`;
    this.progress.style.width = `${pct * 100}%`;
    // dots / labels / value / aria 更新保持
}
```
关键点：
1. this.trackRect 必须在 init、每次拖动开始（pointerdown）时重新 getBoundingClientRect、以及 window resize 时刷新。拖动过程中用最新 trackRect，禁止用陈旧值。
2. 拖动：用 e.clientX - trackRect.left 归一化到 0..1 → Math.round(n * 4) 得档位 index → 仅当 index 变化时调用 setValue（拖动期间实时吸附）。
3. 把 mousedown/mousemove/mouseup 换成 Pointer Events：thumb.addEventListener('pointerdown') → this.thumb.setPointerCapture(e.pointerId) → pointermove 处理拖动 → pointerup 释放。触屏可拖。
4. 保留：点击轨道、点击 label、键盘左右键（aria-valuenow/min/max 已达标继续保留）、档位圆点指示器、激活 label 高亮、进度条填充、干净值显示（"当前 中性 · 03/05"）。
5. 不得再出现 translateX 百分比位移 thumb；thumb 不得再用 scaleX 压扁。

【补回本次构建丢失的动效（上一轮验收发现全丢了）】
1. 鼠标视差：Hero 标题/装饰元素随鼠标位置按不同深度 translate3d 分层位移；mousemove 只记录 target，rAF+lerp 每帧更新；层列表初始化缓存。
2. 磁吸按钮：CTA 按钮在光标进入周边半径时吸附 ≤8px，离开回弹。
3. 3D tilt：作品图片墙卡片 hover 时 rotateX/rotateY ≤6deg，父容器 perspective。
4. prefers-reduced-motion：上述全部动画在该媒体查询下禁用（自定义光标也禁用）。
5. 自定义光标保留现有 translate3d 实现与 cursor:none。
