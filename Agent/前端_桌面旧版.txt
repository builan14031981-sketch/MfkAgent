MfkAgent Frontend Design System Refinement V1

角色：
你是一名资深桌面应用 UI 系统优化工程师。

你的任务不是重新设计 MfkAgent，而是在现有产品基础上，建立统一、稳定、可维护的视觉设计系统。

项目背景：

MfkAgent 是一个桌面 AI Agent 应用。

产品定位：
- Desktop AI Assistant
- Chat-first
- Project Workspace
- Agent Runtime

设计参考：
- macOS 原生应用
- ChatGPT Desktop
- Linear

目标：
让 MfkAgent 具有桌面 AI 应用的质感，而不是普通 Web SaaS 后台风格。


====================

一、任务边界

本任务只进行：

UI 视觉系统优化。

包括：

- 间距系统
- 字体体系
- 行高
- 颜色层级
- 圆角规范
- Sidebar
- Chat 页面
- 输入区域
- Settings 页面视觉统一


禁止：

1. 不改变产品功能
2. 不改变数据流
3. 不修改后端接口
4. 不改变页面架构
5. 不删除已有组件
6. 不引入新的 UI 框架
7. 不创建第二套 Theme / Token 系统
8. 不为了苹果风重做整个 App


优先原则：

复用现有代码。

优先修复：

已有 CSS Variables
已有组件
已有设计体系

而不是重新建立新的体系。


====================

二、执行流程

严格按照以下流程执行。


Phase 1：代码审查（禁止修改代码）

首先检查：

1. 前端目录结构

2. 全局样式文件

3. Theme / CSS Variables

4. UI 基础组件

5. Sidebar

6. Chat 页面

7. Input Composer

8. Settings 页面


重点寻找：

- 间距不统一
- 字体不统一
- 颜色变量混乱
- 硬编码颜色
- 圆角混乱
- 页面密度过高
- 组件风格不一致


输出：

《MfkAgent UI Audit Report》

包含：

1. 当前 UI 问题
2. 问题影响
3. 优化建议
4. 涉及文件


等待确认后进入 Phase 2。


====================

Phase 2：Design System 收敛


建立统一视觉规则。


基础单位：

采用 4px 网格系统。


间距优先：

4
8
12
16
20
24
32
40
48


禁止随意出现：

例如：

13px
19px
27px

除非有明确原因。


====================

三、Typography 规范


建立统一文字体系。


标题：

22-28px


正文：

16px


辅助信息：

13-14px


中文内容：

正文 line-height：

约 1.6


避免：

文字过密
行距过小
信息堆叠


====================

四、Spacing 规范


页面级：

桌面大区域：

24-32px


紧凑区域：

16px


弹窗：

20-24px


组件内部：

16-24px


组件之间：

16-32px


原则：

通过空间建立层级。

不要依赖大量边框。


====================

五、Sidebar 规范


目标：

接近 macOS Finder / Xcode。


建议：

宽度：

220-280px


列表项：

高度：

36-44px


选中状态：

使用弱背景色

圆角：

8px


避免：

后台管理系统式菜单。


====================

六、Chat 页面规范


Chat 是 MfkAgent 核心体验。

优先级最高。


消息区域：

最大宽度：

720-860px


正文：

16px


行高：

约 1.6


消息间距：

16-24px


AI Markdown 内容：

必须保证：

- 标题层级清晰
- 列表间距合理
- 代码块可读
- 表格不会拥挤


不要为了视觉统一降低内容可读性。


====================

七、输入区域规范


Composer 是核心交互。


目标：

接近 ChatGPT Desktop。


规范：

高度：

52-60px


圆角：

16-24px


内部 padding：

16px


保持：

清晰
稳定
易输入


====================

八、颜色系统


苹果美学核心：

减少视觉噪音。


禁止：

- 高饱和颜色
- 大面积渐变
- 强阴影
- 过度玻璃效果


优先使用：

- 背景层级
- 透明度
- 空间关系


修复：

硬编码颜色。

统一使用现有 Theme Variables。


====================

九、圆角规范


统一：

小组件：

8px


普通组件：

12-16px


大型输入区域：

20px


禁止：

每个组件使用不同圆角。


====================

十、修改原则


优先级：

P0：
不破坏已有功能


P1：
统一视觉体系


P2：
提升核心体验


P3：
细节美化


如果视觉优化和功能稳定冲突：

选择稳定。


====================

十一、修改完成后的验证


必须：

运行项目。


检查：

1. Sidebar 是否正常

2. Chat 是否正常

3. 输入框是否正常

4. Settings 是否正常

5. 是否存在布局溢出

6. 是否存在颜色异常

7. 是否存在字体跳动

8. 是否影响已有交互


====================

十二、最终提交格式


完成后输出：

《MfkAgent UI Refinement Report》


内容：

1. 修改文件列表

格式：

- 文件路径
- 修改内容


2. Design System 变化


3. 页面优化说明


4. 风险说明


5. 未修改内容


不要只回复：

“优化完成”。

必须说明具体修改。


====================

最终目标：

让 MfkAgent 看起来像一个成熟的桌面 AI Agent 产品。

不是网页后台。

不是简单套苹果风。

而是：

macOS 原生体验 +
ChatGPT 的交互效率 +
Linear 的设计克制感。
